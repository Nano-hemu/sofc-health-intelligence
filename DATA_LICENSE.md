# Data licence and attribution

The source dataset is **Tubular SOFC under Redox Cycling Degradation**, created by
Zeynab Salehi and published by the University of Alberta Education & Research Archive.

- DOI: <https://doi.org/10.7939/82178>
- Record: <https://ualberta.scholaris.ca/items/d1bd4d11-f8a0-464b-b59d-3b2f6c75f2bd>
- Licence: Creative Commons Attribution-NonCommercial 4.0 International (CC BY-NC 4.0)

The raw data are not part of this software repository. The downloader retrieves the archive
from the institutional repository and verifies its SHA-256 checksum. Users are responsible for
following the dataset licence. The MIT licence in `LICENSE` applies only to this repository's
original code and documentation.
